// NATIVE CONTRACT
Isolated Windows UDP probes covered both socket families and cross-family
queries. The requested input family determines the returned list.
Input shorter than 2 bytes or output shorter than 4: INVALID_PARAMETER.
Unknown family 0/1: successful empty list, Information=4.
Successful populated result: Information=4 plus all transport-address records.
Short output with room for the count: STATUS_BUFFER_OVERFLOW; count and
Information describe the full list, but only complete records are written.
Unwritten bytes and bytes outside the supplied buffer remain unchanged.
The probe saw 3 IPv4 and 6 IPv6 addresses. These are measurements, not constants.

// IMPLEMENTATION
The Windows socket backend queries the owned native endpoint using owned
buffers, first retrieving the required size and then the complete address list.
It retries boundedly if the list grows during collection. Guest pointers are
not sent to the host kernel; guest instructions remain in Icicle.
The AFD handler validates the input, verifies record boundaries, writes complete
records fitting the guest output, and sets the full required Information value.
Short-buffer results retain STATUS_BUFFER_OVERFLOW for mswsock's size handling.
Static/non-Windows socket backends report unsupported instead of fabricating
host interfaces. Address-change notification is a distinct IOCTL.
