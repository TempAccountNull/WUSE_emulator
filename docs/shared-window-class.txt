// What
Populate the guest shared window-class descriptor from the registered class.
Windows user32 reads this structure directly for GetClassLongPtrW; a syscall
handler alone cannot supply those reads. Synchronize supported class changes
across aliases and rebuild the view from registered state after snapshot load.
Reserve class-extra storage before the copied class name. Preserve existing
extra bytes and per-window procedures when the class changes.
