Icicle address-size and subtraction flags

In 64-bit mode, 67h selects a 32-bit effective address. Calculate the complete
RIP-relative, base/index or displacement result at that width, then zero-extend
before adding FS/GS. The former Mem path sign-extended ordinary offsets and
retained high RIP bits. LEA used a different, incorrect SIB-relative rule.

Use the same addr32 calculation for memory and LEA. Keep mod00/rm101
RIP-relative in long mode, including REX.B=1. Preserve displacement-only SIB
addressing. R12D is an index when REX.X=1; six no-index shortcuts omitted that
condition. The default 64-bit address forms remain unchanged.

The trailing-immediate CMP regression also reproduced stale AF. subflags now
calculates the bit-3 borrow for CMP, SUB and its other existing callers. Tests
check all six arithmetic flags for byte, word, dword and qword operands. The
separate ADC/SBB and addition auxiliary-carry omissions are not fixed here.

The existing long-mode EVEX definitions lacked an IA64 include guard, making
the standalone i686 language fail compilation. Both x86 language definitions
now compile. This does not implement compatibility-mode selection, far
transfers or the custom vector helpers' compatibility address semantics.
