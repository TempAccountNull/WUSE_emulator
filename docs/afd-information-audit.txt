// IMPLEMENTATION
AFD_SET_INFORMATION class 2 now changes the guest endpoint blocking state.
Synchronous empty I/O returns STATUS_DEVICE_NOT_READY for nonblocking or
AFD_IMMEDIATE requests. AFD_OVERLAPPED retains pending completion precedence.
This applies to stream/datagram receive and send paths.

SET classes 1, 6, 7, 11, 12 and 15, and GET classes 3, 4, 5, 6, 7, 8, 10 and 14
are routed through the socket backend. The Windows backend issues only these
information controls against its owned native socket, using owned scalar/inline
buffers and a completion event. It propagates the native status and value.
No guest instruction is executed natively and no guest pointer is forwarded.
GET class 4 also includes an outstanding Sogen send request.
Successful GET writes exactly 16 bytes and sets IO_STATUS_BLOCK.Information=16.
Invalid lengths/classes produce errors instead of the previous blanket success.
Each completed information request logs its class, value and status.
